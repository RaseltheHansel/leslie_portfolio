## Getting Started

```bash
npm install
npm run dev
```

## Features
- Profile header with animated hover avatar cycle
- Purple verified badge
- Dark mode toggle via ThemeContext
- AI-powered Chat with Leslie (Claude API)
- Tech Stack, Experience, Projects, Certifications pages
- Recommendations carousel with dot navigation
- Footer info panel (memberships, social, speaking, contact)
- Gallery with scroll arrows
